
# Molecular Toxicity Prediction

## Overview

An undergraduate learning and research project exploring
machine learning applications in molecular toxicity prediction.

The project aims to build and evaluate computational models
using publicly available molecular data.

## Research Objectives

- Understand molecular representations and fingerprints.
- Explore and preprocess the Tox21 dataset.
- Implement baseline machine learning models.
- Compare model performance under different data splits.
- Investigate model limitations and potential data leakage.

## Planned Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- RDKit
- Scikit-learn
- DeepChem

## Dataset

Tox21, a publicly available molecular toxicity benchmark
included in MoleculeNet.
